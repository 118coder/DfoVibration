# S1 高级参数整合 + 优先级阶梯 + S4 特调方案 (v1 讨论稿)

> 日期: 2026-09-10 · 状态: **已实施 §2/§3/§4 (见 §6 实施记录), §5 剩余项待做** · 作者: 会话 AI
> 目的: 回应三条用户意见 —— ① S1 高级参数概念相近、太多; ② 给高级参数定优先级,
> 让"治持续震"的算法不被别的数值压过; ③ 给 S1 加 S4 算法特调, 但不丢震动、可自由调。

> 两侧子代理清点 (控件计数/参数链路/重叠项)。行号为本次通读时的实际行号。

## 0. 结论摘要 (先看这段)

1. **要整合, 而且问题比"看起来多"更严重**: S1 高级区共 **77 个可交互控件** (含总开关),
   其中「群怪不打手」一张卡就 **22 个** (8 复选框 + 14 滑块)。经代码核对, 至少 **9 组是
   同一概念的重复表达**, 其中 3 组在引擎里**共用同一份状态**, 并不是独立算法。
2. **"优先级"真正的含义不是数值大小, 而是"应用顺序 + 谁能否决谁"**。现状有 **6 处低位阶段
   可以复活高位阶段已经杀掉的震动** (输出平滑/爆发保底/抬底重映射/随机抖动/马达增益/
   评分与移动的 max 合成)。用户要的"治持续震优先级高", 落地 = 给战斗通道加一个
   **静音位 (silence latch)**, 让高位阶段归零后低位阶段不得抬回。
3. **S4 特调可行, 推荐做成"输出引擎模式"三选一**: 经典(S1 现行) / S4 纯 / **S4+不丢震动**
   (新档)。新档 = 保留 S1 的分通道事件处理与聚合记账 (不丢任何一击) + 采用 S4 的输出整形
   (真静音死区 / 重映射在后 / 快落地), 并把 S4 的死区%、重映射下限%、衰减 ms 全部做成
   玩家滑块 —— 满足"只要可以自由调整, 丢失震动的问题就能解决"。
4. **红线**: 全程 gate 在 `legacy`(S1); S4 路径逐字节不动; 新行为默认关/默认经典;
   全部走 §9 高级算法纪律 (GUI 可调 + 独立 config 链路 + 双态回归 + vib.log 诊断)。

## 2. 方案一: 参数整合

### 2.1 原则

- **优先做"渐进披露 (progressive disclosure)"**: 概念合组 + 默认只露高层旋钮, 低频/专家旋钮收进"专家模式"折叠。**引擎语义不动** = 零手感风险, 老预设零迁移。
- 只有用户确认后, 才考虑把重叠项在**引擎层**真正合并 (需要参数映射表 + 老配置迁移 + 双态回归)。

### 2.2 建议分组: 群怪不打手 22 → 7 (顶层 3 + 专家 4)

| 新概念组 | 顶层旋钮 (默认可见) | 收进专家的旧旋钮 |
|---|---|---|
| **① 一刀一震 (群怪合并)** | 开关 + "命中聚合窗 ms" | merge_keep / merge_cap / merge_hold |
| **② 每秒最多几下 (限频)** | "每秒最多震几下" | 限频计时窗 |
| **③ 暴增时只震一部分 (风暴)** | 开关 + 阈值 + 保留% | 统计窗 / 停手恢复 ms / 统合衰减 ms |
| 专家: 持续降温 | — | sustain 秒数 / 降幅 |
| 专家: 脉冲落地 | — | 落地阈值 % |
| 专家: 风暴静音 | 两个静音复选框 (保持可见) | — |
| 专家: 统合衰减期 | 开关 (保持可见) | 衰减 ms |

同理: 「连击与自适应」把 密度/命中自适应 合成一个"打太快自动变轻"概念 (顶层 1 开关 +
1 触发 + 1 降幅 + 1 保底), 其余 10 个滑块进专家。整体可从 77 → **约 25 个默认可见**。

### 2.3 若要引擎层合并 (备选, 需用户点头)

- merge/hitcap 合并为单一"记账携带"算法 (本就共用状态), 对外只留一个"保留力度%"与"补发窗口"。
- sustain/density/adapt 合并为单一"自动降温"乘子: 触发 = max(太快, 太密, 太久), 降幅取一个, 保底取一个 —— 消除三者相乘导致的过压/欠压。
- 风险: 会改变现有 ACT 预设手感; 需要逐职业回归。**不建议第一轮做。**

## 3. 方案二: 优先级阶梯 (治持续震不被压过)

### 3.1 现状: 低位阶段能复活高位阶段的静音

| 低位阶段 | 位置 | 复活行为 |
|---|---|---|
| 输出平滑 out_smooth (默认 55) | 2599-2609, 2479-2485, 2578-2584 | 一阶低通, 高位归零后平滑值残留 → 尾巴/嗡嗡回来 |
| 爆发保底 Burst floor | 1821-1823 | `right.max(...)` 把已归零的右马达抬回地板 (仅对 unified 打了补丁) |
| 重映射抬底 (S1 前置 20%×master) | 1919-1929 | 极小非零被抬到 ~18-20% → 本该听不见的尾巴变成可听嗡鸣 |
| 随机抖动 ±N% | 2486-2487, 2611-2612 | 抬高脉冲峰值抖动 (对纯零无效) |
| 马达增益 / 总闸 L/R | 2486-2487, 2611 | 最终叠乘 |
| 评分通道 / 移动通道 max 合成 | 2475-2488, 2574-2586 | 评分脉冲/移动可盖过战斗通道的静音 |

### 3.2 建议阶梯 (高 → 低, 仅 ch=3 普通命中)

```
1. 风暴静音 (mute)              ── 绝对否决, 事件丢弃
2. 脉冲化输出 (统合衰减/落地)    ── 旧包络瞬间死 + 到点硬归零; 置"静音位"
3. 密度治理 (风暴抽样/限频/合并)  ── 决定这一击是否注入、注入多厚
4. 自动降温 (持续/密度/自适应)    ── 降幅
5. 强度参数 (attack/master/max/连击/曲线/随机)
6. 输出整形 (抬底/爆发保底/平滑/分工/马达增益)
```

**核心机制**: 第 2 层归零时置一个**帧内静音位 (silence latch)**; 第 5-6 层凡会"抬回非零"
的动作 (Burst 保底、S1 抬底重映射、out_smooth 平滑插值) 都先查静音位, 命中则跳过。
作用域只限**战斗 (FONT) 通道** —— 评分脉冲、移动通道照常, 不会把别的通道一起闷掉。

### 3.3 落地清单 (拍板后)

- `VibEngine` 新增 `font_silent_l/r: bool` (帧内), 由 tick 的落地/统合/单帧脉冲归零处置位。
- tick: Burst 保底加 `&& !font_silent_r` (把现有 unified 特例推广到落地/单帧)。
- finalize: S1 抬底对"被静音位标记的马达"跳过。
- run 循环: `out_smooth` 在静音位时直接输出 0 (不插值), 避免尾音。
- 诊断行 `[SILENCE]` (每帧状态翻转记一条, 防刷屏)。
- 回归测试: 高位归零后低位不得抬回 (逐阶段红灯测试)。

## 4. 方案三: S4 特调 for S1

### 4.1 三种输出引擎模式 (新增 `legacy_output_mode: u8`, serde default 0)

| 模式 | 名称 | 输出管线 | 事件处理 | 已知特性 |
|---|---|---|---|---|
| 0 | **经典 (现行 S1)** | S1 合成式 max + 线性 + 20% 抬底 + 15% 死区 | S1 分通道 | 群怪负载下靠 22 个旋钮手动压 |
| 1 | **S4 纯** | S4: 抢占式 + 迟滞死区 28% + 重映射在后 | **S4 全局窗** | 质感最干净, 但 S1 事件语义下**会丢击** |
| 2 | **S4 + 不丢震动 (推荐)** | S4 输出整形 (真静音死区/重映射在后/快落地) | **保留 S1 分通道 + 聚合记账** | 干净脉冲 + 每一击都不丢 |

### 4.2 模式 2 的"不丢震动"保证

- 死区杀掉的是"低于阈值的**输出**", 不是"事件"。被死区挡下的能量**转入既有
  `font_carry_s[3]` 记账** (这套机器已经存在: merge/hitcap 就在用它), 下一发注入时
  兑现成"更厚的一击"或到期补发 —— 即"轻反馈攒厚再出", 而不是"轻反馈消失"。
- 保留 S1 的 20ms 分通道注入窗与 IVL 锚点语义 (打戳在间隔门后), 避免"通道饥饿"。
- 模式 2 下 S4 死区**不吞**已记账能量: 兑现时按合并强度输出, 高于死区自然出得来。

### 4.3 玩家可调 (满足"自由调整")

S1 模式下把 S4 的整形旋钮全部解锁 (不再灰掉):

- `输出低强度抑制 % (死区)` — 0 = 不静音, 值越大越"干脆"。
- `重映射最小输出 %` — 决定最小可听强度 (0 = 关闭抬底, 最接近"真静音")。
- `脉冲落地 %` / `统合衰减期 ms` — 衰减节奏 (已有)。
- `输出平滑 %` — 模式 2 下建议默认降到 0 (否则平滑会糊掉脉冲), 但保留可调。
- 提供 **「S1 × S4 特调」预设** (走 §9 预设纪律, 用户可 A/B)。

### 4.4 实现边界 (S4 红线)

- `finalize` 的 `if self.legacy` 分支内按模式分叉; S4 (`!legacy`) 分支一行不动。
- `tick` 的 legacy 分支内按模式选"合成式"或"合成式 + 死区落地"。
- 新增 config 字段走独立链路 (config.vibration → AppState 原子 → run 同步 → 引擎),
  不占 60 槽位。
- 默认模式 0 = 现行行为逐字节不变; 现有 ACT 预设零迁移。

### 用户待实测 (分职业/分场景)

- 经典模式: 手感应与升级前**完全一致** (默认, 零迁移)。
- S4+不丢震动模式: 群怪应有"一击接一击的干净脉冲", 且**每一击都能感觉到**;
  觉得轻反馈被吞 → 调低「输出低强度抑制 %」; 觉得太软 → 调高「重映射最小输出 %」;
  平滑糊了脉冲 → 把「输出平滑 %」降到 0-20。
- S4 纯模式: 作为对照, 低于死区的轻反馈会消失 (预期)。
- 优先级阶梯: 脉冲落地/统合衰减期归零后, 右马达不应被爆发保底抬回 (长按群怪验证)。
