# ADR-0002: 震动参数单一事实源 = vibration/params.rs

- 状态: 已采纳 (2026-09-27)
- 背景: 同一震动参数曾在三处对账 —— `state` 的 `[AtomicU32;60]` 运行态、`vibration` 的
  P_* 下标常量、`config::VibrationConfig` 的 serde 字段；config↔槽位双向映射在
  `state.vibration_params_from` 与 `gui.sync_vib_config_from_params` 各手写一份。
- 决策: `src/vibration/params.rs` 是唯一事实源：
  1. P_* 槽位下标常量（pub(super)，引擎 `use params::*` 保持裸名）；
  2. `for_each_named_param!` 宏表（0-18 具名槽位）唯一生成
     `params_from_config` / `config_from_params` 双向映射；19-59 = `config.advanced[i-19]`
     位置段（config 侧本就是数组）。
  3. state/vib_mirror 与 gui/hints 的旧签名保留为**委托**（callers 零改动）。
- 硬约束（不可违背）:
  - `VibrationConfig` 的 serde 字段名与顺序 = 冻结契约，老 TOML 必须无迁移加载；
  - 引擎算法（algo_on_attack/push_event/tick/输出管线）不因映射改动而变化；
  - 参数值与默认值不变（ACT1 特供校验和 `act_variants_tests` 逐字节锁定）。
- 守卫测试: `params::mapping_tests::config_slot_roundtrip_is_identity`（特征值往返逐字节恒等）、
  `named_table_covers_base_slots`、`vibration_params_tests`、`act_variants_tests`。
- 新增具名参数的步骤: params.rs 宏表加一行 → VibrationConfig 加字段 → （引擎要读时）加 P_* 常量，
  全部在同一目录内完成；跑 `cargo test --lib mapping_tests`。
