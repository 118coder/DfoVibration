# ADR-0004: 构建/测试管线纪律（iter 默认 + ASCII 环境铁律）

- 状态: 已采纳 (2026-09-27)
- 背景: 日常循环误用交付构建（fat-LTO + codegen-units=1）且 `run_tests.bat` 连跑 4 遍；
  2026-09-27 会话沙箱又把 CARGO_HOME/TEMP 重定向到含中文的路径，暴露同类MinGW 链接失败。
- 决策:
  1. `sync_and_build.sh` 默认 `--profile iter`（opt-1/无 LTO/16 CGU/增量）；**交付**才显式
     `bash sync_and_build.sh --release`；
  2. `run_tests.bat` 一遍制（默认 iter 档，参数透传 `--release`/`--lib` 等）；
  3. 同步**先删后拷**（`rm -rf $DST/src tests`）——目录化拆分后残留在构建目录的旧文件会让
     rustc 对同一模块找到两份定义；
  4. 脚本内置 `CARGO_HOME=/c/Users/12290/.cargo`（ASCII 缓存）；**会话内**手动跑 cargo 时
     必须带 `CARGO_HOME=… TMP=/e/Sorahk-build/.tmp TEMP=/e/Sorahk-build/.tmp`
     （非 ASCII 路径会让 MinGW ld 报 `cannot find -lwindows.0.53.0`、doctest 对象文件丢失）；
  5. `cargo build $MODE 2>&1 | tail -1` 必须在 `set -o pipefail` 之下（`| tail` 会掩码退出码，
     曾两次把旧包当新包交付）。
- 实测基线 (2026-09-27): iter 增量构建 6-30s；基线测试 789 个。
