# ADR-0005: 长期保障三层方案（契约护栏 / 演进食谱 / 工程基础设施）

- 状态: 已采纳 (2026-09-27)
- 背景: R1 重构完成后, 用户提出长期目标 —— 软件要能**长期使用**: 未来可扩展、可维护、稳定。
  本项目的长期风险画像: ①serde/TOML 契约靠自觉 ②依赖方向靠约定 ③rustc/工具链漂移会破坏
  MinGW 构建 ④未来 AI 接手时缺标准扩展路径。
- 决策（三层, 全部零运行时语义变化）:
  1. **契约护栏 = 可执行测试** (`tests/architecture_tests.rs`):
     - GUI 外禁止 `crate::gui`（反向依赖, 病历: XInputDeviceInfo/HidDeviceInfo 曾住在 gui
       被 rawinput/xinput 引用, R1.1 已归位到生产者侧）;
     - gui 模块依赖允许清单（钩子/托盘/信号/急退等接线层禁止从 GUI 直接触碰）;
     - config.rs 叶子化（只许依赖 i18n/util）;
     - **serde 字段契约快照**: `VibrationConfig` 79 键 / `AppConfig` 29 键 —— TOML 字段名
       是老配置文件的兼容契约, 快照不一致即红; 有意扩展 = 更新快照常量并在提交写明。
  2. **演进食谱** (`docs/cookbook.md`): 加震动参数 / 加 GUI 页面 / 加客户端形态 / 加设置项 /
     发版 / 重构安全网, 六张标准配方, 每张标注会拦住你的守卫测试。
  3. **工程基础设施**:
     - `rust-toolchain.toml` 钉扎 `1.96.0-x86_64-pc-windows-gnu`（完整三元组防 host 歧义;
       首次使用需 `rustup toolchain install` 一次性下载）; E:\Sorahk-build 暂不钉
       （沙箱 RUSTUP_HOME 受限无法装版本化工具链, 装好后再把文件同步过去）;
     - `.github/workflows/ci.yml`: PR 在干净 Windows runner 自动构建 + 全量测试（runner 走
       MSVC 尽力校验, 本机交付以 MinGW 为准）;
     - git tag: 每个用户确认稳定的版本打 `v<版本>` tag。
- 重新评估触发: runner 环境与本机差异过大导致 CI 长期红 → 改为仅构建不测试或移除 CI;
  工具链钉扎阻碍安全更新 → 升级钉扎版本并全量重跑测试。
