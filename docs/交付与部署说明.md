# 交付与部署说明（维护者向）

> 用户向说明见根目录 [README.md](../README.md) 与发行包内 `使用说明.txt`。
> 本文档面向维护者：交付物构成、部署规则、日志与排障入口。

## 交付物构成

| 文件 | 用途 | 来源 |
|---|---|---|
| `DfoVibration-Sorahk.exe` | 宿主控制面板（连发映射 + 震动 + 白名单 + 全职业预设） | 本仓库 `bash sync_and_build.sh --release`，产物在 `E:\Sorahk-build\target\release\sorahk.exe` |
| `DfoVibration.dll` | 90CN 新一代客户端采集 DLL（战斗事件 → 共享内存） | DLL 源码仓库（V3 版本 `DLL源码\`） |
| `DfoVibration.ini` | 90US 挂载式 DLL 配置（极简，一般无需改） | 同上（90US 变体） |
| `DfoVibration_OLD.dll` | S1 ACT 老客户端系列采集 DLL（ACT1/4/4.5-60US/5/40JP 各一份构建） | 老版 DLL 源码仓库（`E:\LX\DfoVibration_OLD\DLL源码\`，`cmd //c build_old.bat`） |
| `Config.toml` | 连发映射 / 程序配置（用户数据，serde 全量落盘） | 运行时生成 |
| `Vibration.toml` / `Vibration-ACT.toml` | S4 / S1 路线各自震动设定（互不干扰） | 运行时生成 |
| `JobVibration.toml` | 全职业预设状态（应用职业后生成） | 运行时生成 |

## 部署规则

- **自动注入（推荐）**：设置里登记游戏目录后，宿主在游戏启动时自动注入对应 DLL
  （客户端形态表见 `src/auto_inject.rs` 的 `CLIENTS`），DLL 无需手动放置。
- **手动放置**：把对应 `DfoVibration*.dll` 复制到 `游戏目录\us_extend_dll\`；
  宿主 exe 放游戏目录或任意位置均可。
- **权限**：默认普通权限；90CN 场景引导用户右键管理员（见 `docs/使用说明` 历史沿革）。
- **两套路线**：S1（ACT 老版）参数存 `Vibration-ACT.toml`，S4 存 `Vibration.toml`，
  互不串档（`route_isolation_tests` 锁定）。

## 日志与排障入口

| 位置 | 内容 |
|---|---|
| 游戏目录 `us_extend_dll\DfoVibration_dll.log` | 注入侧 DLL 探针日志 |
| exe 同目录 `SorahkDFO_vib.log` | 宿主震动主循环日志 |
| exe 同目录 `SorahkDFO_crash.log` | 仅异常时生成（panic 记录；出现即说明发生过异常但进程存活） |

排障流程 / 两侧日志对齐 / 判定器：见 `docs/开发维护规范.md` §3 与 HANDOFF。

## 应急与保险（用户须知，写进发行包 `使用说明.txt`）

- 强制退出热键：**Ctrl+Alt+Shift+A**（系统级，软件失控时也能生效）
- 注入保险：每秒注入超上限自动冷却 1 秒；输入法打字期间自动暂停映射
- 白名单建议：填入 DNF 主程序 exe 名，只在游戏前台生效
