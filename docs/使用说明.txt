【v1.6 更新要点 (2026-08-30)】
  本版主题: 绝对稳定化 —— 修复“概率性卡住后崩溃”, 并加固全部输入链路。
  1. 任何线程异常只写日志( exe 同目录 SorahkDFO_crash.log ) + 自动重启,
     绝不整进程崩溃; 线程创建失败也不再终止程序。
  2. 事件背压自动合并: 高速连按/来回切键堆积超阈值时只保留每个键最新
     “按下/松开”, 松开必然立即生效 —— 消灭“积压→卡住→松手后狂按”。
  3. 手柄报文/振动 DLL 共享内存按“不可信输入”逐项校验, 异常当场丢弃,
     绝不越界读; 振动 DLL 崩溃时软件不再陪崩。
  4. 注入时长/连发间隔/双击间隔全部钳位安全范围, 配置填错不卡 worker。
  5. 系统回调(钩子/RawInput 窗口过程)整体加防护, 兜底返回默认处理。
  6. 退出更可靠: 关闭最多等 3 秒, 卡住也会直接结束, 不会“点了没反应”。
  详细修复记录: 开发文档\稳定性修复记录_v1.6.md; 简易说明另见 更新说明.txt

【安装】
  1. 把 DfoVibration.dll + DfoVibration.ini 放入 游戏目录\us_extend_dll\
     (如需评分难度插件: DfoRankDiff.dll + DfoRankDiff.ini 同放入)
  2. 把 SorahkDFO.exe 放到游戏目录 (与 DFO.exe 同级)
  3. 启动游戏, 再运行 SorahkDFO.exe

【参数怎么看】
  震动页每个滑块/开关, 鼠标**悬停**都会显示说明, 末尾给出"调高：…；调低：…"
  (开关类为"开：…；关：…"), 一眼看清往哪边调会有什么后果。

【手柄识别 (兼容性增强版 2026-08-29)】
  1. XInput 模式手柄(含国产双模手柄拨到 Xbox 档)插上即自动识别, 无需任何操作。
     XInput 已连接时不会弹出激活窗口(若弹窗说明当前不是 XInput 模式)。
  2. 其他模式(DirectInput/HID)的手柄第一次插入会弹出【设备激活】窗口:
     等待窗口出现后, 按一下再松开任意一个按键即可, 基线自动存入 Config.toml,
     之后每次启动自动识别, 无需重复激活。
  3. 已兼容: 高/低电平有效按键布局、8 字节小报文手柄、Game Controls 页(0x05)
     上报的手柄/方向盘/飞行摇杆。
  4. 找不到手柄时: 重新插拔手柄 → 在设备管理器页点【刷新】→ 若仍无,
     勾选【显示全部 HID 设备】查看是否被系统识别为其它类型。

【应急保险(重要, 2026-08-29 新增)】
  若出现映射/连发失控、键盘鼠标几乎无法操作的情况:
  1. 按住 Ctrl+Alt+Shift+A → 软件立即强制退出, 系统立即恢复。
     (全局热键由 Windows 直接识别, 即使软件自身已失控也能生效; 注册失败时静默跳过。)
  2. 软件内置“注入保险”: 每秒注入超过上限会自动冷却暂停 1 秒, 防止淹没系统输入。
  3. 强烈建议在【设置→进程白名单】填入 DNF 主程序 exe 名(如 DNF.exe,
     可在任务管理器确认实际名称): 这样映射只在 DNF 前台时生效,
     切回桌面/其它程序时自动停止注入, 不会“抢键盘抢鼠标”。
     (白名单为空 = 全部进程启用, 即当前默认状态。)
  4. 中文拼音等输入法打字(组合选字)期间, 软件自动暂停全部映射与注入:
     ① 不拦截按键 → 输入法不会再因收不到 KeyUp 而卡死;
     ② 不注入模拟键 → 手柄映射不会把字母“打”进聊天框。
     打完字按 Esc / 选字完成即自动恢复, 无需任何操作。
     (仅“正在打字”时暂停; DNF 开着拼音但没打字时不暂停, 不影响打副本。)
  5. 连发(涡轮)已做“连招节拍化”处理: 连发键的按下统一按 interval 节拍注入,
     高速连按/来回切键只登记状态、不叠加积压注入周期, 物理松开即停 ——
     从源头消除“狂按技能+来回切键 → 事件积压 → 软件卡死”。
     同时冷却期间整体“透传”(不拦截也不注入): 按键永远直接有效,
     不会再出现“注入被停但按键被吞”的卡死感。
  6. 双连接场景(第三方无线 USB 接收器 + 蓝牙同时连着同一型号手柄):
     默认由 XInput(接收器)接管, 蓝牙那一路的 HID 接口会被跳过,
     避免两路同时注入导致按键加倍/冲突。若需用蓝牙那一路, 请拔掉接收器
     或把接收器那一侧切换为非 XInput 模式。

【绝对稳定化 (2026-08-30 大改版)】
  本轮针对“概率性卡住后崩溃”做了结构性加固, 目标是任何异常都不再杀进程:
  1. 崩溃不再致命: 任何线程发生内部错误(panic)都只记录日志、该线程自动重启
     (最多 10 次后放弃, 但整个程序保持运行), 绝不整进程退出。
     异常详情写入 exe 同目录的 SorahkDFO_crash.log(正常情况不会生成,
     若该文件出现, 说明有异常发生但程序仍活着可继续用)。
  2. 事件背压自动合并: 高速连按/来回切键导致事件堆积超阈值时, 自动丢弃
     中间冗余事件、只保留每个键最新“按下/松开”状态 —— 松开必然立即生效,
     从根上杜绝“积压 → 卡住 → 松手后还在狂按”。
  3. 注入时长自动钳位: 连发 interval / 双击间隔 / 按键持续时长全部限制在
     安全范围, 配置填错(超大/0)也不会让 worker 长时间卡住或空转烧 CPU。
  4. 所有被 Windows 直接调用的回调(键盘/鼠标钩子、RawInput 窗口过程)已加
     防护: 即使内部偶发异常, 也会兜底返回默认处理, 绝不让异常跨系统边界
     导致进程崩溃。
  5. 手柄报文/共享内存全部按“不可信输入”处理: 设备上报的异常报文尺寸、
     振动 DLL 写坏的头尾指针都会当场校验丢弃, 绝不越界读内存。
  6. 退出更可靠: 关闭程序时最多等 3 秒, worker 卡住也会直接结束, 不会
     “点了退出没反应”。
  7. 输入法打字暂停、注入保险、连招节拍化、双连接 XInput 优先等既有保险
     全部保留, 见上文【应急保险】。
