说明
本引擎是纯算法（频带分析 + 自动门槛），不需要下载任何模型文件。
Xbox 手柄只有 2 颗马达（低频 + 高频），震动层次受马达物理限制，不是软件问题。
与 DLL 震动同时开启时两者取最大值合并（互不覆盖）；DNF 内建议只用 DLL 模式（受击更精准），音频模式适合免注入场景与其他游戏。
马达保护：持续高输出 10 秒自动限幅 60% 持续 5 秒（防马达过热）。
换了耳机/音箱/环境之后，建议重新点一次「屏蔽校准」。
白名单条目默认直接复用连发白名单；关掉音频震动时，连发/组合键/DLL 注入行为与旧版完全一致。

▶MOD 开发文档（开发者接入说明 · 精简版）

外观 MOD 是什么

同一个后端、同一份 UiSnapshot 六域快照、同一套 UiCommand 动作词表 —— 不同的「皮」。宿主（本页所在的经典界面）负责数据与命令；主题包只负责外观与壳层。

包结构

  • mod.json —— 清单：name / version / author / description / theme 信息；
  • theme.css + theme.js —— 主题样式与壳层脚本；
  • 预览图（本页主题卡上那张）。

宿主契约

  • 前端只消费 UiSnapshot 六域快照，不直连后端；
  • 全部动作走 UiCommand 动作 id：toggle-pause / save / test-vibration / audio-self-check / check-update 等（完整词表见完整文档）；
  • 提交档位语义：Memory（不落盘）→ Save（落盘）→ Reload（落盘 + 热重载）五档。

生命周期

安装 → 加载 → 应用 → 停用 → 卸载。应用 = 切换 UI 壳层，后端会话不动；停用后回到内置默认「原版经典」。

约束

  • 不得绕过命令契约直连后端；
  • 主题不得改变数据语义（只换视觉）；
  • 跟随宿主安全边界（白名单 / 注入保护提示等必须保留）。
