【快速上手 5 步】
  1. 解压本包到任意目录
  2. 右键「以管理员身份运行」DfoVibration-Sorahk.exe
     (90CN 新版客户端必须管理员, 否则注入被拒)
  3. 首次启动按向导: 是否 DFO 玩家 → 游戏版本 (S1 老版本/S4 新版本)
  4. 插手柄 → 手柄映射页点「快速校对手柄按键」, 按提示按几个键
  5. 点手柄图上的按键绑定目标键; 「通用震动」页开震动 → 进图即有反馈

【包内文件清单】
  DfoVibration-Sorahk.exe   宿主控制面板 (连发/震动/白名单/全职业预设)
  DLL\                      各客户端注入 DLL (宿主会自动注入, 一般不用手动放)
    ├ 90CN-DLL\             新一代客户端
    ├ 90US终末之光-DLL\     (含 DfoVibration.ini)
    ├ 40JP-DLL\ ACT1-DLL\ ACT4-DLL\ ACT4.5-60US-DLL\ ACT5-DLL\
    └                       老版本客户端 (DfoVibration_OLD.dll)
  Vibration.toml            S4 路线震动设定 (模板, 运行后自动维护)
  Vibration-ACT.toml        S1 ACT 路线震动设定 (互不干扰)
  手柄映射键位参考.png       手柄键位参考图

【各客户端 DLL 对照】
  宿主自动注入: 设置里登记游戏目录后, 游戏启动时自动注入对应 DLL。
  手动放置: 复制对应 DLL 到 游戏目录\us_extend_dll\ 即可。
    90CN 新一代        → DfoVibration.dll
    90US 终末之光      → DfoVibration.dll (+ DfoVibration.ini)
    ACT1/4/4.5-60US/5/40JP → DfoVibration_OLD.dll

【应急保险 (重要)】
  1. 映射/连发失控、键鼠失灵: 按住 Ctrl+Alt+Shift+A 立即强制退出软件
     (系统级热键, 软件失控也生效)。
  2. 内置注入保险: 每秒注入超上限自动冷却 1 秒; 输入法打字期间自动暂停映射。
  3. 建议【设置 → 进程白名单】填入 DNF 主程序 exe 名 (任务管理器确认):
     只在游戏前台生效, 切回桌面自动停止, 不抢键鼠。

【手柄识别】
  1. XInput 模式手柄 (含国产双模手柄拨到 Xbox 档) 插上即识别。
  2. 其他模式 (DirectInput/HID) 第一次插入会弹【设备激活】窗口:
     按一下任意按键即完成, 基线自动保存, 之后免操作。
  3. 连不上: 「设置旁手柄图标 → 重置手柄」重新握手;
     非 XInput 手柄在映射页按任意键走 Raw Input 激活。

【常见问题】
  Q 需要管理员吗?  默认普通权限; 90CN 客户端必须右键管理员运行。
  Q 杀毒报毒?      钩子/注入技术可能误报, 加信任列表即可。
  Q 震动没反应?    游戏启动了吗 → 震动开关开了吗 → 设置里游戏目录登记了吗
                   → 通用震动页右下角看「已连接游戏 (累计 N 事件)」。
  Q 分享配置?      直接发 Config.toml (连发) / Vibration.toml (震动);
                   全职业微调用程序导出的 job_export_*.toml。
  Q 参数怎么调?    震动页每个滑块悬停都有「调高/调低」后果说明。

【删除还原】
  删除注入的 DfoVibration*.dll 即完全还原, 游戏零修改。
