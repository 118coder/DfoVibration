## 一、项目定位（一句话）

**DLL 采集游戏战斗事件 → 共享内存 → SorahkDFO 引擎 → XInput 手柄震动**

- 游戏本体一个字不改。
- DLL 只做只读采集（hook 只用在"伤害飘字创建函数"这一处，绝不碰 UI 热路径）。
- 所有反馈算法、参数、UI、预设都在 SorahkDFO 侧调整。
- 最终交付：独立 EXE + 可选挂载 DLL。

## 四、评分系统关键地址（核心研究成果，直接可用）

### 全局对象
| 符号 | 地址 | 含义 |
|---|---|---|
| `n2500` | **0x4294CE8** | 玩家角色对象（vtable 基类） |
| `dword_4187B54` | **0x4187B54** | 评分对象全局指针 |
| `dword_4189A88` | 0x4189A88 | 主对象缓存 |
| `dword_4189A98` | 0x4189A98 | 全局倍率对象 |
| `ui_manager_frame_owner_global` | **0x4189AC0** | UI 管理器（帧 owner） |
| `dword_4189720` | 0x4189720 | 阈值表（8 个 float） |

### 评分对象字段（dword_4187B54 指向）
| 偏移 | 含义 | 读函数 |
|---|---|---|
| +524 | 评分等级（写点 0x1E2B9ED，但 ebx=UI 对象，勿 hook） | `sub_1DD2100` 实时算 |
| +762 | 目标总伤害 | sub_1DD2100 |
| +771 | 伤害修正 | sub_1DD4D60 |
| +2696 | 综合评分值 | sub_1DD4040 |
| +2764 | 累加器（评分点累加） | sub_1DD8D40 |
| +2780 | 结算标志（1=战斗中） | — |
| +3084 | 击杀计数/评分点累加器（明文，读后游戏清零） | sub_1DD9E20 |

**8 槽场景表**：`this + 292*槽号 + 272`，每槽 292 字节；槽号 = `(*n2500+3028)(n2500)` (0~7)。

### n2500 vtable 方法偏移（字节）
| 偏移 | 用途 |
|---|---|
| +76 | 取场景索引 |
| **+856** | **极限闪避状态**（1=闪避中） |
| +1544 | 取容器（参数3） |
| +1580 | 连击容器（解密后是累计命中计数，非实时连击） |
| +3012 | 发送击杀点事件(18) |
| +3028 | 取场景槽号(0~7) |

### 评分核心函数（直接调用签名）
| 函数 | 地址 | 签名 | 用途 |
|---|---|---|---|
| sub_1DD4D60 | 0x1DD4D60 | `int thiscall(score_obj)` | 当前伤害 |
| sub_1DD2100 | 0x1DD2100 | `int thiscall(score_obj, dmg)` | 等级 0~8 |
| sub_1DD3900 | 0x1DD3900 | `double thiscall(score_obj, float slot, uint idx)` | 槽场景值 |
| sub_1DD4040 | 0x1DD4040 | `double fastcall(score_obj)` | 综合评分 |
| sub_1593960 | 0x1593960 | `int usercall(edi)` | 特殊判定（闪避/暴击） |
| GetExtensionPool | 0x2F97E50 | `ptr thiscall(ui_manager)` | 取 UI 对象 |

> **⚠️ 关键坑**：`sub_1DD3900` 第 2 参数 `slot` 是**整数位模式**（IDA `COERCE_FLOAT(6)`），必须用 `slot_bits(n)`（union int→float）传参，传真实 float（如 `4.0f` 位模式 0x40800000）会触发函数内断言 `if(LODWORD(a2)>=0x11) sub_31C4EA1()` → 崩溃。

### 判定语义映射（已确认）
- **槽 4/5 = 破甲**（sub_136CFC0 的 case 8/9；注意 sub_136CFC0 实为**关卡目标条件判定器**，非玩家事件分发）
- **槽 10/14 = 凌空追击**（sub_A9F120 / sub_1370DD0，case 12/13/14）
- **槽 6 = 主评分**
- `sub_1E2D840` (0x1E2D840) = **评分判定分发中心**（switch case 0~15），case 1/2/9/10/14/15 发评分点(事件18)+触发 UI 评价文字槽
- **12 槽评价文字**：`0x041D8C58 + 68*槽号`（+12 文字key / +36 数值 / +40 定时器 3000ms），零 hook 轮询可采；case→槽: 1→5, 2→7, 9→3, 10→2, 14→9, 15→6
- **n2500[5747] (0x59CC) = 击杀计数**（sub_1D1E9F0 每次击杀+1，sub_1DD9960 每秒冲刷→事件14；最终击杀候选）
- 游戏评分数值经 XOR 加密，加密表基址 `dword_42D43E0`(0x42D43E0)；文字 dstr 解密: nkpi_key_unwrap(0x2C65430)，DLL 进程内可直接调用取明文
- 详见 docs/评分判定分发中心与最终击杀_v7.md
